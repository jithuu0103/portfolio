# Indrajith R — ML Engineer Portfolio

A responsive dark navy/blue personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Customize before publishing
In `index.html`, replace:
- `your.email@example.com` with your real email address.
- The GitHub link `https://github.com/` with your GitHub profile.
- The LinkedIn link `https://www.linkedin.com/` with your LinkedIn profile.
- Add verified project repository links and real project results when available.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment and open the published URL shown there.

No build tools or frameworks are required.
